# OmniLink × Husky — README film

[Watch the full film](omnilink-husky-live-ai.mp4).

Recorded on 2026-09-21 in the shipped
[`omnilink_husky.omniworld`](../../../projects/samples/demos/worlds/chat/omnilink_husky.omniworld).
Six instructions use live OmniLink model calls: remember base, drive a one-metre
square, change its direction and size, navigate to a midpoint, ask the distance
from base, and return. Follow the [setup guide](../../guide/omnilink-chat-demos.md)
to connect an OmniKey and model provider. Plans and timings can vary between runs.

Native OmniSim renderer and Newton/MuJoCo simulation. One fixed camera; no
Blender, narration or audio. Final video: H.264, 1920 × 1080, 24 fps,
100.125 seconds. The edit removes waiting and compresses motion from a session
lasting about 14 minutes 42 seconds. It is not a latency benchmark, hardware
demonstration or general accuracy guarantee. Conversation context is shown
within one session; persistence across restarts was not tested in the film.

Machine: Windows 11, RTX 3060 Laptop GPU, fingerprint `9722d23d12a3`.
The full MP4 is copied unchanged from the reviewed final take. `preview.gif`
is the opening 32 seconds, reduced to 720 px wide at 8 fps; it loops and links
to the full video. Internal capture traces and credentials are not media assets.
