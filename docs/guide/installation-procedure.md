## Installation Procedure

OmniSim is currently distributed as source — it is built from a checkout
of the public repository rather than installed from a package manager.
The build instructions live in two places:

- [AGENTS.md §2 — Build](../../AGENTS.md#2-build-only-if-the-binary-is-missing) — the canonical
  copy-paste build path on Windows (MSYS2/MinGW64) and Linux/macOS.
- [Developer Quickstart](../developer/quickstart.md) — full prerequisites
  walkthrough including Qt6, GLM, stb, and platform-specific notes.

Once OmniSim ships numbered releases with prebuilt binaries, this page
will document the per-platform install procedure for those binaries.
Until then, build from source.

The legacy OmniSim installation guide (Debian/Snap/APT for Linux,
DMG installer for macOS, EXE installer for Windows) is preserved in the
[upstream Webots documentation](https://github.com/cyberbotics/webots/blob/released/docs/guide/installation-procedure.md)
for reference — those installers do not produce an OmniSim binary.
