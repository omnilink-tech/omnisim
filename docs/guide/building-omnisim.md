# Building OmniSim

As an alternative to simply [installing a precompiled binary](installing-omnisim.md), OmniSim can also be built from source.

To do so, please refer to the canonical OmniSim build instructions: the [Developer Quickstart](../developer/quickstart.md) and [AGENTS.md §2](../../AGENTS.md), which cover the full from-source build for Windows, Linux, and macOS.
