# Building OmniSim

As an alternative to simply [installing a precompiled binary](installing-omnisim.md), OmniSim can also be built from source.

To do so, please refer to the canonical OmniSim build instructions: the [Developer Quickstart](../developer/quickstart.md) and [AGENTS.md §2](../../AGENTS.md), which cover the full from-source build for Windows and Ubuntu 24.04. macOS is not supported — there is no package, no verified build, and Newton physics is unverified.

On Linux a source build is currently the only route; `bash scripts/install/linux_bootstrap.sh` does the whole sequence. See [Installation procedure](installation-procedure.md).
