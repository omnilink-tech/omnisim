## Examples

OmniSim ships physics plugin examples under `tests/physics/plugins/physics/` (and a starting-point template at `resources/templates/plugins/physics/template.c`).
When opening a world that uses a physics plugin, the code of the physics plugin should appear in OmniSim text editor.
If it does not appear automatically, you can open the source file directly in OmniSim text editor. New physics plugins are created with the menu: `File / New / New Physics Plugin...`.
