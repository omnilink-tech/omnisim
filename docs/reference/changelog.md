# Changelog

## OmniSim Releases

**The OmniSim changelog lives at the repository root: [`CHANGELOG.md`](https://github.com/omnilink-tech/omnisim/blob/main/CHANGELOG.md).**

That file is the single source of truth for OmniSim release notes — it records
every shipped version (v5.0.0, v4.5.0, v4.0.0, v3.0.0, …), follows
[Keep a Changelog](https://keepachangelog.com), and is what the release tooling
reads. This page is a pointer only; do not add release entries here, or the two
will drift.

*(A previous revision of this page stated "No OmniSim release has shipped yet."
That was wrong — OmniSim had already shipped several versioned releases. Corrected
2026-07-11.)*

## Inherited Webots Changelogs

OmniSim is a fork of [Webots](https://github.com/cyberbotics/webots). The upstream
Webots release notes (R2020–R2025) document the baseline OmniSim inherits — they are
**not** OmniSim release notes, and they are **not** vendored in this repository.

Read them at the source, where they are maintained and authoritative:
[github.com/cyberbotics/webots/releases](https://github.com/cyberbotics/webots/releases).
