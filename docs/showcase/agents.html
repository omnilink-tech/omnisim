From sim to real

The agent control surface is simulator-agnostic: the tool names, argument schemas, and HTTP endpoints do not change. Replace the controller with a real-robot bridge and every prompt, every tool, every profile keeps working. Physics and policy transfer are a separate problem and are not claimed — see the scope box in the sim-to-real guide.
