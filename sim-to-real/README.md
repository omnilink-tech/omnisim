# Sim-to-real

Saved comparisons between OmniSim and real robot recordings, with videos,
source data, evidence and links to the runnable projects.

| Study | Status |
|---|---|
| [SO101 pick and place](so101/README.md) | Authored simulation succeeds; exact recorded replay remains unresolved. No hardware transfer validation. |
| [ALOHA battery insertion](aloha-battery/README.md) | A mechanical reconstruction adds spring compression, release and fingertip seating to the archived placement study. Recorded actions fail; compartment parameters are estimated. No hardware transfer validation. |

See also the [shared control surface guide](../docs/guide/omnilink-sim-to-real.md).
