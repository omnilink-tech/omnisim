## The meshes — generated, not authored by hand, and provably so

The shells are **surfaces of revolution** emitted by
[`scripts/dev/gen_omniarm_meshes.py`](../../../../scripts/dev/gen_omniarm_meshes.py)
from `(r, z)` profiles declared inside that script, with analytic per-vertex
normals. Bare URDF `<cylinder>` primitives cannot express a taper or a filleted
rim, and the arm read as a toy without them.

Every file carries its origin **in its own first three lines**, which is the
only evidence that survives a squashed public release:

```
# Generated by scripts/dev/gen_omniarm_meshes.py -- do not hand-edit.
# Surfaces of revolution authored in this repository. Apache-2.0, (c) OmniLink.
# 2184 vertices, 2072 quads, 56 radial segments.
```

Verified 2026-08-24: **16 of 16** files carry both the generator line and the
`Apache-2.0, (c) OmniLink` line.

### The drift gate

`--check` re-emits every mesh from the profiles and compares it byte-for-byte
with what is on disk, so the claim "this geometry is what the committed script
produces" is *checkable*, not asserted:

```bash
python scripts/dev/gen_omniarm_meshes.py           # regenerate
python scripts/dev/gen_omniarm_meshes.py --check   # CI drift gate
```

Measured 2026-08-24: 16 files, 16 `ok`, exit code 0.

**OBJ is a deliberate choice over a binary mesh format.** It is plain text, so a
reviewer can diff it and the drift gate can prove byte equality. There is no
`.stl`, `.dae`, `.glb` or `.fbx` here, and no binary whose origin has to be
taken on trust.

## What the shells are *not*

They are **visual geometry only**. Collision is primitive `<cylinder>` /
`<box>` declared inline in the URDF, and the inertials are carried over
unchanged from the model this package replaced — see
[`../PROVENANCE.md` § Physical parameters](../PROVENANCE.md). Visuals do not
participate in physics, so the shells are not derived from, and need not match,
the collision or inertial data.

## Adding geometry here

Add it to `gen_omniarm_meshes.py` and regenerate. A hand-placed mesh would pass
the provenance gate (this file confers coverage on the directory) and fail
`--check`, which is the wrong way round: the gate would say "recorded" while the
record said "generated" and the two would disagree silently.
