OmniSim PBR appearance PROTO icons.

Contents
--------
68 PNG files, one per PROTO in the parent directory
`projects/appearances/protos/` -- from `Asphalt.png` to `WornBurlap.png`.
Each is the preview render the GUI shows for that appearance in the
Add-Node dialog and the scene-tree icon column.

Limits
------
Upstream never published a per-asset origin record for the appearance
library, so this states the licence Cyberbotics DECLARED, not an independent
determination of where each render came from. That declaration is theirs to
make and it is recorded per PROTO. Cyberbotics carves restricted assets out
individually -- other Webots assets ship under "Licensed for use only with
Webots" -- and no file in this directory or in ../textures/ is inside that
carve-out. See docs/developer/texture-provenance.md for the full derivation.
