# Print jobs: provenance

- `cube20.stl`: a 20 mm calibration cube, generated by OmniLink with `trimesh.creation.box`
  (Apache-2.0, like the rest of this directory).
- `cube20_sv08.gcode`: that cube sliced by `cura_slice.py` (CuraEngine 5.3, set from the SV08
  profile in `../../machines/sovol_sv08/sovol_sv08.json`). Slicer output; no third-party content.
