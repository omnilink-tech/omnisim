# Laser jobs: provenance

- `tag_3mm_plywood.gcode`: written by `../job.py` (`job.tag()`, regenerate with
  `python projects/manufacturing/laser/job.py --out projects/manufacturing/laser/jobs/tag_3mm_plywood.gcode`).
  The feeds, power and passes are Sienci Labs' published LaserBeam settings for 3 mm
  plywood (https://resources.sienci.com/view/lb-material-guide/); the shape and the file
  are OmniLink's own work, Apache-2.0 like the rest of this directory.
