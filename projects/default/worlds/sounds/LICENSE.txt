Limits of that evidence
-----------------------
The election above rests on in-file authorship metadata plus the upstream
repository's blanket Apache-2.0 grant. It is NOT backed by a per-file copyright
notice from Cyberbotics, because no such notice exists — a `.wav` has nowhere to
put a licence header. This repository's history is a squashed import, so git
cannot corroborate anything earlier than the import commit. What would settle it
beyond doubt: a written confirmation from Cyberbotics Ltd. that these audio
files are covered by the Webots Apache-2.0 grant.

Usage — DO NOT DELETE
---------------------
All five are live: they are the schema DEFAULT values of node fields, so every
world that does not override them resolves to these paths.

    bump.wav             ContactProperties.bumpSound   (resources/nodes/ContactProperties.wrl:14)
    roll.wav             ContactProperties.rollSound   (resources/nodes/ContactProperties.wrl:15)
    slide.wav            ContactProperties.slideSound  (resources/nodes/ContactProperties.wrl:16)
    linear_motor.wav     LinearMotor.sound             (resources/nodes/LinearMotor.wrl:13)
    rotational_motor.wav RotationalMotor.sound         (resources/nodes/RotationalMotor.wrl:13)

The same five defaults are mirrored for the web viewer in
resources/web/wwi/protoVisualizer/FieldModel.js and documented in
docs/reference/{contactproperties,linearmotor,rotationalmotor}.md.

(Aside, unrelated to licensing: contact *sound* produces no audio on the Newton
physics backend. The field defaults still resolve, so the files are still read.)
