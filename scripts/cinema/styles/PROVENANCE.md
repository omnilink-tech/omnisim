# Provenance — `scripts/cinema/styles/`

`omnilink-minimal-reference.png` is **OmniLink's own work**: a frame rendered by
OmniSim's native renderer from this repository's own world, kept as the approved
visual reference for the minimal OmniLink demo style described in
[`../OMNILINK_DEMOS.md`](../OMNILINK_DEMOS.md) — one robot, one arena, fixed
oblique camera, a small signature at upper left and one rounded prompt card.
No third-party footage, artwork or typeface artwork is present in it.
