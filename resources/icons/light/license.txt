OmniSim GUI icon set. light/ is the DISABLED state; dark/ is the same artwork in the
enabled colour. Both are generated by scripts/dev/gen_gui_icons.py.

Sources
-------
1. Google Material Symbols - Apache License 2.0.
   https://github.com/google/material-design-icons
   The toolbar and menu glyphs (open, save, copy, paste, play, pause, step, search, ...)
   are rendered from the upstream "materialsymbolsoutlined" SVGs and recoloured to the
   enabled/disabled palette. Apache-2.0 permits this; attribution is given here and in
   THIRD_PARTY_NOTICES.md at the repository root.

2. OmniSim original artwork - Apache License 2.0 (c) OmniLink.
   The six viewpoint glyphs (front/back/left/right/top/bottom_view) and the small UI
   primitives (tree branches, spinbox arrows, dock buttons, checkbox mark, ...) have no
   Material equivalent and are drawn from scratch by the generator.

Regenerating
------------
    python scripts/dev/gen_gui_icons.py resources/icons

History
-------
This set previously consisted of icons8 glyphs distributed under Creative Commons
Attribution-NoDerivs 3.0. That licence permits only verbatim redistribution, while these
files had been modified (recoloured into the enabled/disabled pair), so the set was being
used outside its terms. It was replaced in v5.0.0 with the Apache-2.0 sources above.
No icons8 artwork remains.
