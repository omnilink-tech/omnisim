# OmniSim production fonts

`Sora.ttf` is the variable Sora family (weights 100–800). It sets the
OmniSim wordmark: "OmniSim", mixed case, SemiBold (600), no extra tracking.
The wordmark SVGs carry it as outlines, so they do not need the font
installed; `scripts/branding/outline_omnisim_wordmark.py` regenerates them.

Source: https://github.com/google/fonts/tree/main/ofl/sora (version 2.000)

Downloaded 2026-11-03 from the Google Fonts repository. Distributed under
the SIL Open Font License 1.1; see `OFL-Sora.txt` alongside the font.

`SpaceGrotesk.ttf` is the variable Space Grotesk family (weights 300–700),
the display and body family for everything except the wordmark (captions,
film titles, the brand book's running text). It set the wordmark until
2026-11-03.

Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Downloaded 2026-09-08 from the Google Fonts repository. Distributed under
the SIL Open Font License 1.1; see `OFL-SpaceGrotesk.txt` alongside the font.
