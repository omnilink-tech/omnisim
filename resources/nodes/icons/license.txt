OmniSim scene-tree node icons.

Contents
--------
84 PNG files, one per node type (Accelerometer.png ... Zoom.png), all 128x128
RGBA. They are shaded renders of the node they name -- 1,000 to 5,200 unique
colours per file -- not flat glyph artwork.

Where they are used
-------------------
The engine registers this directory as Qt's `icons:` search path
(src/omnisim/gui/OmGuiApplication.cpp:96), which the scene-tree view and the
Add-Node dialog resolve node-type icons through. They are also referenced by
absolute raw.githubusercontent.com URL from the web viewer's field model
(resources/web/wwi/protoVisualizer/FieldModel.js).

4. The artwork is consistent with in-house production: they are renders of
   OmniSim/Webots node types, which only the simulator can produce.

Limits of that evidence
-----------------------
No individual file carries a copyright notice (a PNG has nowhere natural to put
one, and these carry no tEXt/iTXt/zTXt chunks at all). This repository's history
is a squashed import, so git cannot corroborate anything earlier than the import
commit. The election therefore rests on the upstream repository's blanket
Apache-2.0 grant plus the scoping evidence in point 3, not on a per-file notice.

Stale entries (housekeeping, not a licensing issue)
---------------------------------------------------
Fluid.png, ImmersionProperties.png and DifferentialWheels.png name node types
that no longer exist in this engine (Fluid and ImmersionProperties were removed
with the ODE backend in bdc02139). They are harmless -- an icon with no node is
never looked up -- but they can be deleted whenever someone is in here.
