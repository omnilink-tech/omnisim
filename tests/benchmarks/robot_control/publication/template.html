What these numbers measure

Measured outcomes

Success requires all operator turns to pass measured pose, path, object-state and response checks. A tool accepting a command is not enough. Each episode starts in a fresh simulator session.

A declared scope

{{TASKS}} authored tasks, {{FAMILIES}} task families, one model and one Windows machine. These tasks informed development. There has been no independent replication, blind holdout claim or validation on real hardware.

Complete accounting

Total model cost and elapsed task time across successes, failures and errors are divided by completed episodes. A failed job still consumes time and money.
