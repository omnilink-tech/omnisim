# A Husky works a shift — 2026-09-21

**50 prompts · 3.0 minutes · 24.5 m driven · $0.1134**

```
python tests/benchmarks/shiftdemo/run_cascade.py --dry          # price it
python tests/benchmarks/shiftdemo/run_cascade.py --limit 50
```

An operator talks to a Husky the way a person actually would — shift
start, jobs, a forklift near-miss, someone quoting a rule written for a
different machine, small talk, park up. The robot executes, refuses, or
answers. Every penny is counted.

## ⚠️ What this does NOT show

**Not the 26,916× figure.** In a conversation each prompt is about one
robot command, so there is nothing to amplify and the thesis ratio does
not apply. An earlier version of this runner printed a counterfactual
anyway and it came out at **0.9× — i.e. "cheaper to use a model"** —
which is a category error, not a finding. The line is gone, and the
runner now says in its own output what it does and does not measure.

The amplification case is a *repetitive* job, and it is measured
separately in [soak](../soak/RESULTS_2026-09-20.md): **4,648 robot
commands over two hours for $0.00.**

So the two numbers to quote together are:

- **talking** to a robot costs about **a fifth of a cent per thing said**
- **working** it costs **nothing**, for as long as you like

## Two failed runs, and why they are written down

Both produced confident output that was worth nothing. Neither would have
been caught by reading the summary.

**1. `$0.0000` for 100 prompts.** Looked like a triumph. The OmniLink
account's provider grant is lapsed, so all 82 prompts that reached the
relay died on `invalid_grant`, no model was ever called, and 39 of 54
commands silently failed. The runner also mislabelled auth failures as
"refused by the gate", which is how a dead credential came to look like
a working safety feature.

**2. 72 commands dispatched, 0.0 m driven.** The cascade run stripped
`OMNI_KEY` "to be safe", which removed the relay — and `/tool` dispatches
through `relay.tools[...]`, so every command returned 503. It still
printed a cost. The relay's *provider* grant being broken is irrelevant
here; `/tool` only needs the tool registry.

The common shape: **a number that looks like success because the thing it
measures never happened.** The fix in both cases was to judge by the
robot's pose, which is why `distance driven` and the per-kind table are
now the headline and the dollar figure is not.

## One false refusal, found and fixed

`"we'll find out later. square her up — 90 degrees right."` was refused
as `deferred`. The word *later* belonged to the previous sentence; the
order was in the present. It was the only failed command in the run.

Bare time adverbs are no longer deferral triggers — a subordinating
conjunction defers structurally, an adverb floating in the paragraph does
not. `"once the shift ends, drive forward"` and `"in ten minutes"` are
still caught.

## Reproducing

Needs a Vertex service-account credential for the model tier. `--dry`
prices the run without calling anything, `--limit N` shortens it, and
`--budget-usd` aborts mid-shift if measured spend passes the cap.
